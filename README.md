# Eventora — Event Ticket Booking System
## About the Project
Eventora is a responsive front-end website for browsing events and booking tickets. It is developed using HTML, CSS, and JavaScript as part of the Sysslan IT Solutions Front-End Development Internship task.

## Features
- Responsive website for desktop, tablet, and mobile
- Navigation bar with Home, Events, Booking, and Contact sections
- Event cards with images, dates, locations, venues, and ticket prices
- Event search and filtering
- Interactive Book Ticket buttons
- Show/hide event details
- Booking form with name, email, event selection, and ticket quantity
- Front-end form validation
- Booking confirmation message

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Fonts and event images

## How to Run the Project
1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or run it using the Live Server extension.
4. Browse events and test the booking form.

## How to Use
1. Visit the Events section.
2. Browse the available events.
3. Click **Book Ticket** on your chosen event.
4. Fill in the booking form.
5. Submit the form to see the booking confirmation.

## Limitations
This is a front-end demonstration project. It does not include a backend database, real ticket issuance, payment processing, or server-side booking storage.
