# Eventora — Event Ticket Booking System

A responsive front-end internship project based on the five levels in the Sysslan IT Solutions Front-End Development Task List PDF.

## Files
- `index.html` — semantic page structure, navigation, event cards, event details, booking form, footer.
- `style.css` — visual design, event cards, responsive layouts, mobile navigation styling, form states.
- `script.js` — category filters, search, detail toggles, event selection, ticket total, validation, and demo confirmation.

## Run locally
1. Download and extract the project ZIP.
2. Open `index.html` in a browser, or use the VS Code **Live Server** extension.
3. Try filtering/searching events, opening event details, clicking **Book ticket**, changing ticket quantity, and submitting the booking form.

## Important
This is a front-end demonstration only. It does not process payments, save bookings to a server, send emails, or issue real tickets. Event dates and venue details are sample content for the project demo.

## PDF task mapping
- **Level 1 — Structure:** page title, header, sections, navigation, intro and footer.
- **Level 2 — Styling:** fonts, colors, spacing, navigation and footer styling.
- **Level 3 — Event UI:** multiple cards, graphic event artwork, booking buttons and details.
- **Level 4 — Interaction:** button state, details toggles, booking form and input validation.
- **Level 5 — Responsive design:** desktop/tablet/mobile layouts, consistent styling and usability checks.
